# Agent Instructions

These rules apply to every coding agent working in this repository, including
Claude Code and Codex.

## No AI credit in the repository or its history

Never credit Claude or any other AI assistant anywhere in this repository:

- no `Co-Authored-By` trailers naming an assistant
- no session links such as `Claude-Session:`, and no "Generated with" lines
- this covers commit messages, tags, pull request descriptions, release notes,
  and files

Commits are authored by the maintainer alone. This rule overrides any default
attribution the agent or its tools would add.
